これまでの演習では、Copilot クラウドエージェントに、ユーザーエクスペリエンスの改善や機能追加を目的とする 3 つのタスクを依頼しました。クラウドエージェントは非同期かつ自律的に作業しますが、タスクを監視することも重要です。

クラウドエージェントに割り当てたタスクは、GitHub.com の[エージェントページ][agents-page]など、さまざまなツールで管理できます。このコントロールセンターでは、オープンな pull request (PR) があるすべてのエージェントタスクを確認できます。エージェントが実行した操作を調べたり、進行中のセッションを誘導したりできます。

このレッスンでは、次の作業を行います。

- エージェントページでクラウドエージェントのタスクを監視します。
- 進行中のセッションに追加機能を依頼します。

## シナリオ

エージェントにハイコントラストモードを作成するよう依頼した後、チームはライトモードも追加する良い機会だと考えました。サイトのスタイルと切り替え機能を更新しているため、まとめて実装するのが適切です。ハイコントラストに加えてライトモードも追加するよう、エージェントを誘導します。

## Copilot クラウドエージェントのタスクを確認する

Copilot クラウドエージェントに割り当てたすべてのタスクの状態を確認しましょう。

1. [Copilot エージェントのページ](https://github.com/copilot/agents)に移動します。
2. メインペインと左ペインの両方に表示されるタスクの一覧を確認します。Copilot に割り当てた次のタスクなどが表示されます。
   - コードベースのドキュメントの更新
   - ゲーム変更用 API の生成
   - Web サイトへのハイコントラストモードの追加
3. 実行中のタスクを選択し、Copilot が完了した作業を確認します。次のような操作が含まれる場合があります。
   - リポジトリのチェックアウト
   - Copilot の作業環境の作成
   - MCP サーバーの設定
   - 割り当てられたタスクを完了するための各種操作

> [!NOTE]
> 表示される手順は、Copilot の作業状況や採用した方法によって異なります。

4. 右側に表示される pull request (PR) ペインも確認してください。PR と変更されたファイルが表示され、さらに詳しく監視できます。

## クラウドエージェントを誘導する

現在実行中のタスクを確認できました。次に、ハイコントラストモードに取り組んでいる Copilot に、ライトモードの切り替え機能も追加するよう依頼します。

1. ハイコントラストモードを追加するセッションを選択します。正確なタイトルは Copilot が付けた名前や作業状況によって異なります。

    ![mission control でアクセシビリティセッションを表示した画面](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業が始まったことを示すメッセージが表示されるまで、数分間セッションを確認します。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

    ```plaintext
    ハイコントラストモードの作業に加えて、ライトモードも追加してください。利用者が表示モードを選べるように、ライトモードの切り替え機能も用意してください。
    ```

    ![Copilot のエージェントページにある、実行中のセッションを誘導するダイアログを示した画面](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを受け取り、作業の流れに追加したことを確認します。

## Copilot の作業を見守る

前回と同じように、Copilot は更新されたタスクに取り組みます。メッセージを送信した時点で作業中だった手順を終えると、新しい依頼が作業の流れに追加されます。

今回も完了まで数分かかります。その間に、これまでに学んだことを振り返りましょう。

## まとめと次のステップ

このレッスンでは、Copilot クラウドエージェントのタスクを監視してガイドするための中心的な場所である Copilot エージェントページを確認しました。このコントロールセンターで、実行中および完了済みのタスクを追跡し、作業を確認して、進行中のタスクの範囲や追加の指示を変更できます。

次の内容を学びました。

- mission control とエージェントページでクラウドエージェントのタスクを監視する方法
- 進行中のセッションに追加機能を依頼する方法

Copilot がアクセシビリティ機能を実装している間に、次は [Copilot が作成した pull request を改善][next-lesson]しましょう。
